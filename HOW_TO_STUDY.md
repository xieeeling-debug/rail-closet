# How to Study (Beginner Playbook)

## The 3-pass method for every lesson

1. **Skim (5–10 min)** — headings, code samples, “you will learn”  
2. **Do (30–60 min)** — type every example; change numbers/text; break it; fix it  
3. **Teach (5–10 min)** — explain the idea in your own words in a notes file  

If you skip pass 2, you are reading, not learning.

---

## Active learning beats passive watching

| Weak | Strong |
|------|--------|
| Only watching videos | Typing code while pausing |
| Copy-paste without thinking | Retype, then modify |
| Memorizing syntax lists | Building tiny programs |
| Skipping errors | Reading error messages slowly |

---

## When you get stuck (use this order)

1. Read the error message from the **top** (or first red line).  
2. Check spelling, quotes, indentation, missing `:` or `)`.  
3. Compare your code to the lesson example **line by line**.  
4. Add a `print(...)` / `console.log(...)` to see values.  
5. Simplify: comment out half the code; find what still works.  
6. Write the goal in one sentence; list 3 steps in English.  
7. Take a 10-minute break, then retry.  
8. Ask for help with: what you tried, the error text, and your goal.

## Spaced practice

- Revisit yesterday’s exercise for 10 minutes before new material.  
- Once a week: redo an old mini project from scratch without looking.  
- Once a month: explain a topic to a friend (or rubber duck).

---

## Time boxing

If a bug eats more than **25 focused minutes**, write down what you know, switch to a different exercise, and return later. Fresh eyes fix more than tired staring.

---

## Avoid these traps

- Jumping to React before HTML/JS basics  
- Collecting 20 courses and finishing none  
- Waiting until you “feel ready” to build a project  
- Comparing your day 10 to someone’s year 3  

---

## Motivation for absolute beginners

Feeling lost in week 1–4 is normal. Programming is a new literacy. The people who succeed are not the “naturals” — they are the ones who **show up again after confusion**.

Keep PROGRESS.md updated. Small checks compound.
