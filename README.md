# Software Engineer Learning Path

**For complete beginners — zero computer science required.**

This repository is a **full offline course**. After you clone or download it from GitHub, you can open every lesson on your computer **without internet**.

> **Note:** This course is published on its own Git branch so the Closet app on `main` stays untouched. For offline use, download ZIP from the branch page (Code → Download ZIP) or clone with `--single-branch` as shown below.

### How to get it offline (one-time)

**Option A — Download ZIP (easiest)**

1. Open https://github.com/xieeeling-debug/rail-closet/tree/software-engineer-course
2. Click the green **Code** button → **Download ZIP**
3. Unzip on your computer
4. Open `START_HERE.md` in any text editor or Markdown viewer (VS Code recommended)

**Option B — Clone with Git**

```bash
git clone -b software-engineer-course --single-branch https://github.com/xieeeling-debug/rail-closet.git software-engineer-course
cd software-engineer-course
```

Then open `START_HERE.md`.

## What you will learn

| Track | Topics |
|-------|--------|
| **Foundations** | How computers & the web work, files, terminals, Git |
| **Python** | Variables → functions → files → projects |
| **Statistics** | Mean, variance, probability, charts — with Python |
| **Web** | HTML, CSS, JavaScript, responsive pages |
| **Apps** | Build interactive apps (including React) |
| **Software engineering** | Git, testing, debugging, portfolios, job prep |

**End goal:** think and work like a junior software engineer — build real projects, explain your code, and keep learning independently.

| Pace | Hours / week | Rough path length |
