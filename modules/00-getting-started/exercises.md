# Module 00 — Exercises

## Exercise 1 — Map your computer

Write in `notes/day-setup.md`:

1. Where will you keep coding projects? (path)  
2. Where is this course folder? (path)  
3. Screenshot or list of tools installed (Python, VS Code, Git).

## Exercise 2 — Terminal treasure hunt

From your home folder:

1. Create `learning-lab/treasure`.  
2. Create file `clue.txt` with the text `open sesame`.  
3. Use `cd` and `ls` only (no GUI) to prove you can find it.  
4. Write the commands you used into `notes/terminal-hunt.md`.

## Exercise 3 — Markdown resume stub

Create `learning-lab/notes/future-resume.md` with:

- Name  
- Goal: Software Engineer  
- Skills to learn (Python, Statistics, HTML, Apps)  
- One project idea you care about  

## Exercise 4 — Git diary

Initialize Git in `learning-lab` (if not done) and make **3 commits** over a few days as you add notes. Paste `git log --oneline` into `notes/git-log.txt`.

## Stretch

Explain to a friend (or voice memo) what Git is, without jargon.
