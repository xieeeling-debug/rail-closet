## Why VS Code?

VS Code is a free **code editor**:

- Opens whole folders as projects  
- Colors your code (syntax highlighting)  
- Built-in terminal  
- Extensions later (Python, Prettier, etc.)  

### Setup tips

1. Install VS Code.  
2. File → Open Folder → `software-engineer-course`.  
3. Install extensions when prompted: **Python**, **Markdown preview**.  

Open a lesson `.md` file → press `Ctrl+Shift+V` (Windows/Linux) or `Cmd+Shift+V` (Mac) for preview.

## Markdown crash course

Markdown is plain text with light formatting — perfect for notes and READMEs.

```markdown
# Heading 1
## Heading 2

**bold** and *italic*

- bullet one
- bullet two

1. numbered
2. list

`inline code`

```python
print("code block")
```

[Link text](./README.md)
```

(In real files, code fences use three backticks — see any lesson source.)
