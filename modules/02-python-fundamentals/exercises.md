# Module 02 — Exercises

Do these in `learning-lab/python/`. Name files clearly.

## Easy

1. **Intro line** — print your name, a goal, and today’s date (typed as text).  
2. **Rectangle** — functions `area(w, h)` and `perimeter(w, h)`.  
3. **Fizz stub** — for numbers 1–30, print the number; if divisible by 5, also print `~hi5`.

## Medium

4. **Grade labeler** — input score → print letter grade.  
5. **Shopping total** — list of prices; print total, average, max.  
6. **Closet counter** — list like `["top", "bottom", "top", "shoes", "top"]`; count each type with a loop (no fancy libraries).

## Challenge

7. **Password checker** — require length >= 8 and at least one digit. (Hint: `character.isdigit()`)  
8. **Quiz app** — 3 questions in lists; keep score; print final percent.
