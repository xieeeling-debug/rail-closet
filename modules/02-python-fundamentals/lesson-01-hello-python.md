# 02.1 — Hello Python

## You will learn

- How to run a `.py` file  
- What `print` does  
- Comments  

## Create your first program

1. Create file `learning-lab/python/hello.py`  
2. Type exactly:

```python
# This is a comment — Python ignores it
print("Hello, future software engineer!")
print("I am learning Python.")
```

3. In the terminal (same folder):

```bash
python3 hello.py
```

You should see two lines of text.

## What happened?

- `print(...)` tells Python to display something.  
- Text in quotes is a **string**.  
- Lines run from top to bottom (sequence).  

## Experiments

Change the messages. Add a third `print`. Remove a quote on purpose — read the error. Fix it.

## Common issues

| Problem | Fix |
|---------|-----|
| `python3: command not found` | Try `python` or install Python |
| File not found | `cd` into the correct folder |
| Weird quotes | Use straight `" "` not fancy Word quotes |
