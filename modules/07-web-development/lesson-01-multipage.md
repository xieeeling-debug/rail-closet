# 07.1 — Multi-page Sites and Navigation

## You will learn

- Site information architecture  
- Shared look across pages  
- Simple routing with files  

## Structure

```text
mysite/
  index.html
  about.html
  projects.html
  css/styles.css
  js/main.js
  images/
```

Keep navigation consistent on every page. Duplicate HTML nav is OK for beginners; later tools reduce duplication.

## Naming and linking

```html
<a href="index.html">Home</a>
<a href="about.html">About</a>
<a href="projects.html">Projects</a>
```

## Practice

Build a 3-page learning journal site: Home, Notes, Projects. Same header/footer style on all.
