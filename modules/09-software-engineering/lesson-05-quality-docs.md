# 09.5 — Code Quality and Documentation

## You will learn

- Naming and small functions  
- README skills  
- Comments that help  

## Quality basics

- Names describe intent: `count_tops` not `ct`  
- Functions do one job  
- Delete dead code  
- Consistent formatting  

## README template

```markdown
# Project name

What it does in one paragraph.

## Features
- ...

## How to run
```bash
python3 main.py
```

## What I learned
- ...
```

## Comments
