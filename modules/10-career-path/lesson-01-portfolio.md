# 10.1 — Portfolio Strategy

## You will learn

- What hiring managers glance at  
- How many projects you need  
- How to present them  

## Portfolio recipe (beginner → junior)

Aim for **3 solid projects**, not 20 empty tutorials:

1. **Python + data/stats** — analysis script + report  
2. **Web site** — responsive HTML/CSS/JS  
3. **Interactive app** — Closet Mini / habit tracker / React app  

Each project needs:

- Live demo **or** clear screenshots + run instructions  
- README with problem → approach → learnings  
- Clean Git history if possible  

## Pin on GitHub

- Profile README (`username/username`)  
- Pin your best repos  
- Keep descriptions short and outcome-focused  

## Practice

Write titles + 2-sentence pitches for your 3 portfolio projects (even if not finished).
