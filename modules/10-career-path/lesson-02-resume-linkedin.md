# 10.2 — Resume and LinkedIn Basics

## You will learn

- How to describe projects without CS jargon overload  
- Honest beginner positioning  

## Resume bullets (pattern)

**Verb + what you built + tech + outcome/learning**

Examples:

- Built an offline closet filter web app using HTML, CSS, and JavaScript with localStorage persistence  
- Analyzed a personal expense dataset in Python; computed summary statistics and wrote findings  
- Developed a React mini-app to pair clothing items; practiced component state and filtering  

## Sections to include

- Header + contact  
- Summary (2 lines): transitioning into software engineering; skills  
- Skills: Python, HTML/CSS, JavaScript, React, Git, Statistics basics  
- Projects (detail these!)  
- Education / coursework (this course counts as structured study)  
- Experience (any — highlight problem-solving, even non-tech)  

## LinkedIn

- Headline: “Aspiring Software Engineer | Python · Web · React”  
- About: story + what you’re building  
- Featured: project links

Draft 5 resume bullets for projects you plan to finish.
