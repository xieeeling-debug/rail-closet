# 10.3 — Interview Types Explained

## You will learn

- What to expect  
- How to prepare without panic  

## Common rounds

| Type | What it tests | How to prep |
|------|---------------|-------------|
| Recruiter screen | Story, motivation, logistics | 60-second pitch |
| Behavioral | Teamwork, conflict, learning | STAR stories |
| HTML/CSS/JS practical | Build UI, debug | Timed small tasks |
| Python practical | Scripts, data wrangling | Re-do course projects timed |
| DSA (later) | Algorithms | Separate study track |
| System design (later) | Large systems | After you have experience |

## STAR method

- **S**ituation  
- **T**ask  
- **A**ction  
- **R**esult  

Prepare stories: debugging win, learned something hard, collaborated, finished a project.

## Honest beginner tip

You do not need every interview type on day one. Internships, apprenticeships, junior roles, and internal transfers all exist. Strength of **projects + clear thinking** matters enormously at entry level.
