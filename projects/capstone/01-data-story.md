# Capstone C1 — Data Story

## Goal

Tell a true story with data using Python + statistics.

## Deliverables

1. Dataset (your own or sample)  
2. Analysis script  
3. Charts (text OK)  
4. 1–2 page report: question, method, findings, limits  
5. README  

## Evaluation

Clarity of question and honesty about limits matter as much as code.
