# Offline Access Guide

## Get the materials

**GitHub (course branch):** https://github.com/xieeeling-debug/rail-closet/tree/software-engineer-course

### Download ZIP

1. Open the repo on GitHub.  
2. Code → Download ZIP.  
3. Unzip.  
4. Open `START_HERE.md`.

### Clone

```bash
git clone -b software-engineer-course --single-branch https://github.com/xieeeling-debug/rail-closet.git software-engineer-course
cd software-engineer-course
```

## What works fully offline

- All Markdown lessons  
- HTML/CSS/JS files opened in a browser  
- Python standard library scripts  
- Cheatsheets and progress tracker  

## What may need internet occasionally

- First-time installs (Python, VS Code, Node packages)  
- `pip install matplotlib` / `npm install`  
- Live APIs  

## Suggested offline kit

Keep a USB or cloud folder with:

- This course ZIP  
- Python installer  
- VS Code installer  
- Node LTS installer (optional)
