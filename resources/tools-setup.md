# Tools Setup (Beginner)

## Python

1. Install Python 3 from python.org (Windows: tick “Add to PATH”).  
2. Check: `python3 --version` or `python --version`.  
3. VS Code extension: Python.

## VS Code

1. Install from code.visualstudio.com.  
2. Open folder `software-engineer-course`.  
3. Helpful extensions: Python, ESLint (later), Markdown Preview.

## Git

1. Install Git.  
2. Set name/email:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## Node.js (for React modules)

Install LTS from nodejs.org when you reach Module 08.

```bash
node --version
npm --version
```

## Offline tip

Download this repo as ZIP while online. After that, Markdown lessons, HTML practice, and Python standard library work without internet.
