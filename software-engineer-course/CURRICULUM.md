# Full Curriculum Roadmap

Follow modules **in order**. Each module has lessons, exercises, and a checkpoint.

Legend: 📖 lesson · ✍️ exercise · 🛠️ project · ✅ checkpoint

---

## Phase A — Foundations (Modules 00–01)

**Goal:** Use your computer like a builder, not only a consumer.

| # | Module | Lessons | Outcome |
|---|--------|---------|---------|
| 00 | [Getting Started](./modules/00-getting-started/) | Computer, files, terminal, editors | Comfortable with folders & commands |
| 01 | [Thinking Like a Programmer](./modules/01-thinking-like-a-programmer/) | Algorithms, bugs, breaking problems down | Plan before coding |

**Checkpoint A:** Write steps (in plain English) to solve 3 everyday problems, then convert one into a tiny Python script in Module 02.

---

## Phase B — Python (Modules 02–03)

**Goal:** Speak a real programming language fluently enough to automate and analyze.

| # | Module | Focus |
|---|--------|-------|
| 02 | [Python Fundamentals](./modules/02-python-fundamentals/) | Variables, types, input/output, if/else, loops, lists, functions |
| 03 | [Python Intermediate](./modules/03-python-intermediate/) | Dicts, files, errors, modules, simple packages |

**Checkpoint B:** Build a CLI “gradebook” or “expense tracker” that saves to a file.

---

## Phase C — Statistics with Python (Module 04)

**Goal:** Understand data well enough to compute, visualize, and interpret — not just memorize formulas.

| Topics | Skills |
|--------|--------|
| Populations vs samples | Mean, median, mode |
| Variance & std deviation | Percentiles |
| Probability basics | Distributions intuition |
| Correlation (intro) | Charts with Python |

**Checkpoint C:** Analyze a small CSV (grades, expenses, or closet counts) and write a 1-page interpretation.

---

## Phase D — Web Front End (Modules 05–06)

**Goal:** Build pages people can open in a browser.

| # | Module | Focus |
|---|--------|-------|
| 05 | [HTML & CSS](./modules/05-html-css/) | Structure, layout, responsive design |
| 06 | [JavaScript Basics](./modules/06-javascript/) | Variables, DOM, events, fetch intro |

**Checkpoint D:** Personal “About Me + Projects” website, responsive, with one interactive JS feature.

---

## Phase E — Web & App Development (Modules 07–08)

**Goal:** Build multi-file apps like real products.

| # | Module | Focus |
|---|--------|-------|
| 07 | [Web Development](./modules/07-web-development/) | Forms, localStorage, APIs, accessibility, deployment concepts |
| 08 | [App Development](./modules/08-app-development/) | Components, state, React intro, tying to RAIL Closet |

**Checkpoint E:** Build a small app (todo, habit tracker, or mini closet filter) with clear UI and state.

---

## Phase F — Software Engineering & Career (Modules 09–10)

**Goal:** Work like a professional and prepare for jobs.

| # | Module | Focus |
|---|--------|-------|
| 09 | [Software Engineering](./modules/09-software-engineering/) | Git workflows, testing, debugging, code quality, collaboration |
| 10 | [Career Path](./modules/10-career-path/) | Portfolio, resume, interview basics, learning forever |

**Checkpoint F:** Public portfolio with 3 projects + README stories + GitHub profile.

---

## Capstone projects (pick at least 2)

See [projects/](./projects/).

1. **Data story** — Python + statistics on a dataset you care about  
2. **Static site** — HTML/CSS/JS personal brand site  
3. **Interactive web app** — JS or React tool (closet, budget, quiz, etc.)  
4. **Engineer showcase** — tests + Git history + clear docs  

---

## Weekly rhythm (recommended)

| Day type | Activity |
|----------|----------|
| Learn days (3) | 1 lesson + notes |
| Practice days (2) | Exercises only |
| Build day (1) | Project time |
| Review day (1) | Redo weak spots + update PROGRESS.md |

---

## After this course

Continue with:

- Deeper backend (APIs, databases)  
- Mobile (React Native / Flutter) if you want phones specially  
- CS fundamentals (data structures & algorithms) for interviews  
- Domain you love (data, product, education, fashion-tech, etc.)  

Your path does not end here — this course makes you **self-sufficient**.
