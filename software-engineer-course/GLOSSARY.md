# Glossary — Plain-English Definitions

Use this when a word feels scary. Add your own entries at the bottom.

| Term | Meaning |
|------|---------|
| **Algorithm** | A clear step-by-step recipe to solve a problem |
| **API** | A way for programs to talk to each other (like a menu of requests) |
| **Argument / Parameter** | Values you give a function to work with |
| **Array / List** | An ordered collection of items |
| **Boolean** | True or false |
| **Browser** | App that shows websites (Chrome, Firefox, Edge, Safari) |
| **Bug** | When code does not do what you intended |
| **CLI / Terminal** | Text interface where you type commands |
| **Commit** | A saved snapshot of your project in Git |
| **Component** | A reusable UI piece (button, card, page section) |
| **CSS** | Language that styles HTML (colors, layout, fonts) |
| **Dataset** | A collection of related data (often in a table/CSV) |
| **Debug** | Finding and fixing bugs |
| **Deploy** | Putting your app somewhere others can use it |
| **Dictionary / Object** | Named keys mapped to values |
| **DOM** | The browser’s live tree of HTML elements you can change with JS |
| **Framework** | A structured toolkit (e.g. React) that guides how you build |
| **Function** | A named reusable block of code |
| **Git** | Tool that tracks versions of your files |
| **GitHub** | Website that hosts Git projects |
| **HTML** | Language that structures web page content |
| **IDE / Editor** | App for writing code (VS Code) |
| **JavaScript (JS)** | Language that makes web pages interactive |
| **Library** | Reusable code someone else wrote that you can import |
| **Loop** | Repeat instructions until a condition ends |
| **Mean** | Average: sum ÷ count |
| **Median** | Middle value when data is sorted |
| **Module** | A file (or package) of related code you can import |
| **Open source** | Code shared publicly for others to use/learn from |
| **Path** | Location of a file, e.g. `Documents/course/lesson.md` |
| **Pseudocode** | Fake code in plain language used for planning |
| **Python** | Beginner-friendly programming language used widely in data & apps |
| **React** | Popular library for building UI apps from components |
| **Repository (repo)** | A project folder tracked by Git |
| **Responsive** | Layout that adapts to phone, tablet, desktop |
| **Runtime** | When the program is actually running |
| **Server** | Computer that responds to requests (serves websites/data) |
| **State** | Data that can change over time in an app (e.g. selected outfit) |
| **Statistics** | Methods to summarize and reason about data |
| **String** | Text data, e.g. `"hello"` |
| **Syntax** | Grammar rules of a programming language |
| **TypeScript** | JavaScript with optional type checking (used in many apps) |
| **UI** | User interface — what people see and click |
| **Variable** | A named box that holds a value |
| **Variance / Std. deviation** | How spread out numbers are |
