# Software Engineer Learning Path

**For complete beginners — zero computer science required.**

This folder is a **full offline course**. After you clone (or download) this repository from GitHub, you can open every lesson on your computer **without internet**.

---

## Your GitHub link (online + offline)

| Access | Link / action |
|--------|----------------|
| **Online (browse on GitHub)** | Open this repo → folder `software-engineer-course/` |
| **Offline (recommended)** | Clone or download ZIP, then open files locally |

### How to get it offline (one-time)

**Option A — Download ZIP (easiest)**

1. Open the GitHub repository page.
2. Click the green **Code** button → **Download ZIP**.
3. Unzip on your computer.
4. Open `software-engineer-course/START_HERE.md` in any text editor or Markdown viewer.

**Option B — Clone with Git**

```bash
git clone https://github.com/xieeeling-debug/rail-closet.git
cd rail-closet/software-engineer-course
```

Then open `START_HERE.md`.

> Tip: Install [VS Code](https://code.visualstudio.com/) and open the `software-engineer-course` folder. You can read Markdown, run Python, and preview HTML in one place.

## What you will learn

| Track | Topics |
|-------|--------|
| **Foundations** | How computers & the web work, files, terminals, Git |
| **Python** | Variables → functions → files → projects |
| **Statistics** | Mean, variance, probability, charts — with Python |
| **Web** | HTML, CSS, JavaScript, responsive pages |
| **Apps** | Build interactive apps (including React, like RAIL Closet) |
| **Software engineering** | Git, testing, debugging, portfolios, job prep |

**End goal:** think and work like a junior software engineer — build real projects, explain your code, and keep learning independently.

## Suggested pace

| Pace | Hours / week | Rough path length |
|------|--------------|-------------------|
| Casual | 5–7 | ~9–12 months of steady practice |
| Focused | 10–15 | ~5–7 months |
| Intensive | 20+ | ~3–4 months |

Pace is flexible. **Consistency beats speed.** Finish Module 00 before rushing ahead.
