# Start Here — Welcome, Future Software Engineer

You do **not** need a computer science degree, prior coding experience, or “math talent” to begin. You need curiosity, a computer, and regular practice.

This page sets you up in one sitting (~30–60 minutes).

---

## 1. What software engineering actually is

Software engineers **solve problems by writing instructions computers can follow**.

Examples:

- A website that shows your closet photos → web app  
- A script that calculates average scores → Python + statistics  
- An phone-friendly outfit picker → app development  

You will learn the **language** (Python, HTML, JS), the **math tools** (statistics), and the **craft** (Git, debugging, design).

## 5. Rules that make beginners succeed

1. **Type code yourself** — do not only read. Muscle memory matters.  
2. **Break things on purpose** — then fix them. That is learning.  
3. **One concept at a time** — finish the lesson exercises before skipping ahead.  
4. **Explain out loud** — if you cannot explain it simply, you do not own it yet.  
5. **Build tiny projects early** — even ugly projects teach more than perfect notes.  

---

## 6. What “done” looks like for this course

You are ready to call yourself a **junior-capable learner** when you can:

- [ ] Write Python scripts that read data and compute stats  
- [ ] Build a multi-page HTML/CSS site that works on phone and desktop  
- [ ] Add interactivity with JavaScript  
- [ ] Build a small React (or similar) app with state and components  
- [ ] Use Git commits and explain your project in a README  
- [ ] Debug with print/logs and break problems into steps  

Then keep building portfolio projects and applying for roles / internships.
