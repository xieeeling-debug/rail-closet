## You will learn

- What a program is  
- Hardware vs software

## Hardware vs software

- **Hardware** — physical parts (laptop, screen, keyboard, phone).  
- **Software** — instructions that tell hardware what to do (apps, websites, games).  

You are learning to **write software**.

## What is a program?

A **program** is a list of instructions.

Example in plain English:

1. Ask the user for their name.  
2. Save that name.  
3. Show “Hello, \<name\>!”  

Later, Python will look like:

```python
name = input("What is your name? ")
print("Hello,", name)
```

Same idea — clearer rules for the computer.

## Languages

Computers do not understand English well. Programmers use **programming languages**:

| Language | Common use in this course |
|----------|---------------------------|
| Python | Scripts, statistics, automation |
| HTML | Page structure |
| CSS | Page look |
| JavaScript | Page behavior |
| TypeScript / React | Larger apps (like RAIL Closet) |

You do not need all of them on day one. We stack them gradually.

## What happens when you visit a website?

Simplified story:

1. You type a address (URL) like `https://example.com`.  
2. Your browser asks a **server** for the page.  
3. The server sends **HTML** (structure), often **CSS** (style) and **JavaScript** (behavior).  
4. Your browser draws the page on screen.  

Later you will create those HTML/CSS/JS files yourself.
