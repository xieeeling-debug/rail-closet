# 04.6 — Mini Analysis Project

## Goal

Analyze a small dataset end-to-end and write a short report.

## Dataset options (pick one)

### Option A — Use the sample CSV in this course

See `practice-code/python/sample_closet.csv` (created in practice-code).

### Option B — Make your own

Create `my_data.csv` with 15–30 rows. Ideas:

- Study minutes per day  
- Expenses  
- Closet items  
- Workout reps  

## Required outputs

1. Python script that loads the data  
2. Mean / median for at least one numeric column (or counts for categories)  
3. One measure of spread **or** a category frequency table  
4. One chart (text bars OK)  
5. `analysis_report.md` using the story template from lesson 05  

## Rubric

## Checkpoint C

You can explain to a non-technical friend: what average means, why spread matters, and one thing your data suggests.
