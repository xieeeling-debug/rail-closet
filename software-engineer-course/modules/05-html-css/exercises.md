# Module 05 — Exercises

1. Recreate a simple “Closet Categories” page with headings and lists for Tops, Bottoms, Shoes.  
2. Add CSS variables:

```css
:root {
  --bg: #f6f1e8;
  --ink: #14201b;
  --accent: #0f6b4c;
}
```

Use them for background, text, and links.  
3. Build a flex header.  
4. Add a media query that increases padding on large screens.  
5. Validate your HTML mentally: do all tags close? Is there one `h1`?
