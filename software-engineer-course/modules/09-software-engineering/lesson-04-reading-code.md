# 09.4 — Reading Other People’s Code

## You will learn

- How to approach unfamiliar codebases  
- Questions to ask while reading  

## Strategy

1. Read README first  
2. Find the entry point (`main.py`, `main.tsx`, `index.html`)  
3. Skim folder names  
4. Search for a feature keyword  
5. Trace one user action end-to-end  

## Questions

- Where does data live?  
- What happens on click X?  
- Which function owns this rule?  
- What would I rename for clarity?  

## Practice

Spend 30–45 minutes reading RAIL Closet `src/` and update your tour notes with one traced user action (e.g. applying a filter).
